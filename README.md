# Victor Decorações

E-commerce completo especializado em **cortinas, persianas e produtos para decoração**, desenvolvido para oferecer uma experiência de compra moderna, intuitiva e semelhante à de grandes marketplaces, como o Mercado Livre.

A plataforma permite que o cliente navegue pelo catálogo, pesquise produtos, aplique filtros, visualize detalhes, escolha variações, adicione produtos ao carrinho, informe o endereço de entrega e conclua sua compra.

---

## 1. Sobre o projeto

A **Victor Decorações** é uma plataforma de comércio eletrônico voltada inicialmente para o segmento de cortinas e decoração.

O objetivo é criar uma experiência de compra completa, profissional e escalável, permitindo que o cliente encontre facilmente o produto desejado, compare opções, selecione medidas e cores e realize todo o processo de compra diretamente pelo site.

A plataforma deve transmitir uma sensação de:

* Loja profissional;
* Marketplace;
* Segurança;
* Facilidade;
* Organização;
* Variedade;
* Confiança;
* Experiência moderna de compra.

O projeto deve ser construído pensando não apenas na aparência visual, mas também na estrutura necessária para futuramente operar como um e-commerce real.

---

# 2. Objetivos

## Objetivo principal

Criar uma loja virtual completa para venda de cortinas e produtos de decoração.

## Objetivos secundários

* Facilitar a busca por produtos;
* Permitir filtros avançados;
* Apresentar produtos de forma visual;
* Permitir seleção de cores;
* Permitir seleção de medidas;
* Permitir escolha de quantidade;
* Criar carrinho de compras;
* Criar checkout;
* Calcular frete;
* Permitir cadastro e login;
* Permitir acompanhamento de pedidos;
* Criar área do cliente;
* Permitir avaliações;
* Criar sistema de favoritos;
* Criar cupons;
* Criar promoções;
* Criar estrutura preparada para pagamentos reais;
* Criar estrutura preparada para integração com APIs externas;
* Permitir crescime
